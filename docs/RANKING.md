# 종목별 랭킹

## 화면과 집계

- 하단 랭킹(`/ranking`) → 농구·러닝·축구 탭. 러닝에만 5km·10km·하프(21.0975km)·풀(42.195km) 필터를 표시합니다.
- 상위 3개 항목은 큰 카드에서 이름·순위·대표 성적·세부 성적·데이터 출처를 모두 표시합니다. 농구는 승패·경기 수·승률, 축구는 승무패·득실차·승점, 러닝은 달성일·최고 기록을 확인할 수 있습니다. 내 항목은 테두리와 내 팀/내 기록 문구로 구분합니다.
- 아래 **나머지 순위**는 상위 카드에 표시된 세 항목을 제외하고 이어집니다. 공동 순위 계산은 그대로 유지하며, 상위 카드도 정렬 결과의 첫 세 항목만 표시합니다. 전체 항목이 3개 이하면 아래 목록을 숨기고, 기록이 없으면 빈 상태를 안내합니다.
- 계정에 연결된 내 순위/내 팀 순위 요약과 집계 기준을 제공합니다. 기본 집계 기간은 전체 기간입니다. 긴 이름·세부 성적은 줄바꿈하며 작은 화면·큰 글자에서는 상위 카드를 세로로 배치합니다.
- 화면을 왼쪽으로 넘기면 **농구 → 러닝 5km → 러닝 10km → 러닝 하프 → 러닝 풀 → 축구**, 오른쪽으로 넘기면 반대로 이동합니다. 양 끝에서 순환하지 않습니다. 터치와 웹 미리보기의 마우스 드래그를 지원합니다. 기존 종목·거리 버튼으로도 바로 선택할 수 있으며 현재 화면과 선택 표시가 동기화됩니다.
- 러닝 버튼은 마지막으로 본 러닝 거리로 이동하고 최초 거리는 5km입니다. 각 화면은 세로 스크롤 위치를 보존하며, 계정 변경 시 선택 페이지·거리 기억·스크롤을 초기화합니다. 계정별 최초 종목 선택 기준은 기존과 같습니다.
- 제목·새로고침·종목 버튼과 러닝 거리 버튼은 공통 헤더에 고정하고, 랭킹 제목부터 아래 내용만 좌우로 넘깁니다. 헤더에서 가로로 드래그해도 페이지가 바뀌지 않습니다.
- 종목 이름과 버튼은 고정한 채 초록 선택 배경이 손가락을 따라 이동합니다. 러닝 네 거리 안에서는 종목 배경을 유지하고 거리의 초록 배경이 같은 방식으로 이동합니다. 러닝 진입·이탈에 맞춰 거리 버튼 영역의 높이·투명도를 전환하며, 취소하면 원래 상태로 돌아옵니다.
- 버튼 직접 선택은 본문을 즉시 이동하고 선택 배경과 거리 버튼 펼침/접힘을 180ms로 전환합니다. 모션 줄이기 설정에서는 추가 전환 효과를 생략합니다.
- 헤더 높이는 가용 높이의 최대 45%로 제한합니다. 낮은 가로 화면·큰 글자에서 헤더 내용이 넘치면 헤더 내부에서 세로로 스크롤할 수 있어 본문과 모든 버튼에 접근할 수 있습니다.
- 거리 버튼은 같은 너비와 고정된 위치를 유지하고 초록 배경만 이동합니다. 큰 글자로 버튼이 화면 너비를 넘으면 가로 스크롤로 모든 거리를 선택할 수 있습니다.
- 농구: 최소 5경기 이상, 승률 내림차순. 반올림 전 정확한 비율로 비교하며 같은 승률은 공동 순위입니다. 경기 수가 부족한 내 팀은 집계 대기로 표시합니다.
- 축구: 승 3점·무 1점·패 0점, 승점 → 득실차 → 다득점순. 모두 같으면 공동 순위이며, 경기 수 0인 팀은 집계 대기입니다.
- 러닝: 거리별 계정당 가장 빠른 완주 기록 1개, 같은 시간이면 공동 순위. 같은 계정·거리의 운영자 입력 실기록이 있으면 해당 계정의 예시 기록은 제외합니다. 최고 시간이 같은 여러 기록은 먼저 달성한 기록을 표시합니다.
- 공동 순위 다음은 인원만큼 건너뜁니다(1·1·3위). 동일 성적의 표시 순서는 항목 ID로 고정합니다.
- 팀 소속은 성적 항목에 연결한 회원 ID, 러너는 연결한 계정 ID로 확인합니다. 표시 이름이 같다는 이유로 내 순위를 연결하지 않습니다. 연결되지 않은 러닝 항목은 각각 별도 러너입니다.

## 운영자 입력

로그인 → 운영자 로그인 → 운영 관리 → 랭킹 → **종목별 성적 관리**.

1. 종목과 러닝 거리를 선택하고 **성적 등록**을 누릅니다.
2. 팀은 누적 승·무·패(농구는 승·패), 축구 득점·실점을 입력합니다. 내 팀 순위에 표시할 회원 계정을 선택할 수 있습니다. 이 연결은 랭킹 표시용이며 실제 팀 가입을 생성하지 않습니다.
3. 러닝은 표시 이름·거리·완주 시간(`HH:MM:SS`)·달성일(`YYYY-MM-DD`)을 입력하고 러너 계정을 연결합니다. 시간은 1초~23시간 59분 59초, 날짜는 2000년부터 오늘까지입니다.
4. 이름은 2~30자, 경기 성적은 각각 0~9999 정수입니다. 예시는 예시 데이터 스위치로 구분합니다.
5. 수정·삭제 즉시 순위를 다시 계산합니다. 러닝 최고 기록을 삭제하면 남은 기록 중 최고 기록으로 변경됩니다. 저장 실패 시 기존 기록·순위·변경 이력을 보존하고 입력값을 유지하므로 재시도할 수 있습니다.

운영자 인증은 기존 서버 확인 절차를 사용합니다. 일반 회원은 저장·삭제할 수 없으며, 인증 만료와 통신 실패를 안내합니다. 기본 예시 36개(농구 6팀, 축구 6팀, 러닝 4거리×6명)를 제공합니다. DEMO 농구·축구 계정은 예시 내 팀, 러닝 계정은 예시 내 기록을 볼 수 있습니다.

## 저장 호환성과 범위

- 기존 `RankingEntry`·`rankings`와 홈 주간 운동 횟수 TOP 3를 보존합니다. 운영 관리의 **기존 주간 활동 랭킹**에서 계속 편집합니다.
- `OperationsData.sportRankings`에 종목별 성적을 추가했습니다. 이전 저장 형식에 이 키가 없으면 기본 예시를 읽고, 명시적인 빈 목록은 그대로 유지합니다. 저장소 버전은 변경하지 않습니다.
- `SportRankingEntry`에 종목·계정 연결·팀 성적·거리·완주 시간·달성일·예시 여부를 저장합니다. 기존 회원·설문·일정·모집 데이터와 기존 API 형식은 유지합니다.
- `MemberRepository`/`MemberController`의 `saveSportRanking`, `deleteSportRanking`, `refreshRankings`를 통해 기존 권한·저장·변경 이력 흐름에 연결합니다.
- 새로고침은 이 기기의 운영 데이터를 다시 읽습니다. 실패 시 마지막 목록을 유지하고 재시도 버튼을 제공합니다. 로딩 중 중복 요청을 막습니다. 여섯 화면은 조회 결과를 공유하며 화면 전환만으로 추가 조회하지 않습니다.
- 현재 체크아웃된 공유 코드의 저장 방식은 기기별 로컬 저장입니다. Notion에 기록된 다른 브랜치의 공용 계정·DB 구현은 이 브랜치의 코드에 포함되어 있지 않습니다. 경기 결과 수집, 상대 팀 승인, GPS 측정, 실제 팀 관리, 공용 랭킹 서버 연동은 별도 기능입니다.
