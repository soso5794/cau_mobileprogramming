# 재실행 후에도 같은 계정 사용하기

## 원인과 수정

회원정보는 `PreferencesMemberStore`가 `exercise_assist_members_v1` 키로 저장합니다. 웹에서는 브라우저의 localStorage를 사용합니다. 저장 키나 기존 회원 데이터 형식은 변경하지 않았습니다.

`flutter run -d chrome`은 기본적으로 임시 Chrome 프로필을 만듭니다. Flutter의 브라우저 캐시 복원은 최선의 노력 방식이므로 일반 Chrome 또는 다른 실행 프로필과 동일한 저장 공간을 보장하지 않습니다. 주소의 포트가 바뀌거나 `localhost` 대신 `127.0.0.1`을 사용해도 별도 저장 공간이 됩니다. 기존 README와 서버 README에 서로 다른 웹 포트가 적혀 있어 이를 7363으로 통일했습니다.

## 실행 방법

프로젝트 루트에서 실행합니다.

```sh
bash tool/run_web.sh
```

준비 완료 메시지 후 **일반 Chrome의 같은 프로필**에서 **http://localhost:7363**을 엽니다. 이미 열어둔 탭은 새로고침합니다. 서버를 종료하고 다시 위 명령으로 실행해도 같은 저장소를 읽습니다. 스크립트는 브라우저 데이터 삭제나 프로필 생성을 하지 않습니다. 7363이 이미 사용 중이면 기존 앱 서버를 종료하거나 실행 중인 앱을 이용하세요. 자동으로 다른 포트로 이동하지 않습니다.

VS Code에서는 이 저장소를 루트로 열고 실행 구성 **운동 Assist · 계정 유지 웹 (localhost:7363)**을 선택합니다. 같은 주소를 일반 Chrome에서 열어 사용하세요. 설정은 [Dart Code 공식 실행 구성](https://dartcode.org/docs/launch-configuration/)의 `deviceId`와 `toolArgs`를 사용합니다. web-server 모드는 Chrome 장치 직접 실행보다 디버깅 기능이 제한됩니다.

SMTP·운영자 인증·AI에는 별도 서버가 필요합니다. 다른 터미널에서 `npm start --prefix server`를 실행하세요.

## 로그인 화면과 계정 삭제는 다릅니다

- **로그인 상태 유지 켬:** 일반 계정의 로그인 상태도 복원합니다.
- **로그아웃 또는 로그인 상태 유지 끔:** 계정·설문·일정은 남아 있으므로 기존 이메일과 비밀번호로 로그인합니다. 재가입할 필요가 없습니다.
- **운영자:** 보안상 앱 재실행 후 재로그인이 필요하지만, 계정을 다시 생성할 필요는 없습니다.
- **다른 브라우저/프로필/주소 또는 시크릿 창:** 기존 저장 공간에 접근할 수 없습니다. 가입했던 환경에서 확인하세요.
- **사이트 데이터 삭제:** 서버 회원 DB가 없으므로 자동 복구되지 않습니다. 기존 임시 프로필이 삭제된 경우에도 복구를 보장할 수 없습니다.

다른 컴퓨터·휴대폰에서도 같은 계정과 데이터를 사용하려면 일반 회원 서버 인증과 공용 DB가 필요합니다. 이번 수정은 개발 중 실행 환경을 고정하며 서버 회원 DB를 추가하지 않습니다.
