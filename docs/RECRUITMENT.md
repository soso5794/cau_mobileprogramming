# AI 모집글 작성

기준: main `1c7b4db794244c736bc50d8ccdc44edf619b01b0` (2026-11-25 제공 ZIP).

## 실행

프로젝트 루트에서 `flutter pub get`, `flutter analyze`, `flutter test`, `flutter run -d edge`.
DEMO 계정 → 커뮤니티 → 농구(또는 관심 종목) → 모집글 작성 → 장소 입력 → AI 없이 직접 작성 → 제목/본문 확인 → 모집글 등록 (내 기기). 등록 후 해당 커뮤니티 상단에 글이 나타나고 상세 화면을 볼 수 있다.

AI 생성은 별도 터미널에서 `cd server`, `npm ci` 실행 후 `.env.example`의 설정을 `.env`에 작성하고 `npm start`를 실행한다. 기존 `.env`를 덮어쓰지 않는다. `OPENAI_API_KEY`는 서버에만 둔다. `OPENAI_RECRUITMENT_MODEL=gpt-5.4-mini` 기본값은 환경 변수로 변경 가능하며 기존 채팅 모델과 독립이다. Flutter Web은 기본적으로 `http://127.0.0.1:8787`을 사용한다. 모델 접근 권한과 API 실제 응답은 별도 검증 필요.

## 설계

- 종목별 커뮤니티에서 해당 종목으로 미리 채워진 작성 화면을 연다. 진입 위치는 `AppRoutes.recruitmentCreate(sport)`로 변경 가능하다.
- 운동 날짜/시각, 장소, 최소·최대 모집 인원, 강도, 종목별 조건, 자유 입력, 병합 허용 여부를 입력한다. 같은 날짜 내 미래 일정만 허용한다. 인원은 모집할 사람 수이며 현재 참여자 수는 집계하지 않는다.
- 티어·목적·비용 UI는 없다. 병합 체크 기본값은 false이며 실제 병합을 실행하지 않는다.
- 생성 API `/api/recruitment/generate`는 구조화된 제목(60자), 본문(1000자), 추가 조건(최대 12개)을 반환한다. AI 결과는 사용자가 검토하며 확정 전 자동 게시하지 않는다. 수동 모드도 지원한다.
- 기존 `RecruitmentPreview`/`OperationsData`를 재사용하고 구조화 입력, 작성자 ID, 확인된 추가 조건을 추가 저장한다. 기존 예시/운영자 데이터는 이전 형식 그대로 읽을 수 있다. 별도 저장소를 중복 생성하지 않는다.
- 일반 회원 등록 메서드는 신규 글만 생성하고 기존 운영자 메서드의 인증은 유지한다. 운영자는 회원 글을 삭제할 수 있으나 기존 운영자용 편집 폼으로 회원 글의 구조화 조건을 바꾸는 것은 방지한다.
- 같은 브라우저/기기의 여러 계정에서 확인 가능한 로컬 시연용이다. 서버 공유 DB, 참가 신청, 실제 티어 매칭, 실제 병합, 회원 등록 후 수정/삭제는 이번 범위가 아니다. 홈은 수정하지 않았으며 기존 추천 함수의 동작을 따른다.

## 지도 및 장소 검색 (v3)

- 모집글 작성 → 지도에서 장소 선택 / 주소 검색. 지도 화면 상단 검색창, 지도 탭/확대/축소, 검색 결과 선택, 장소명 확인, 이 장소로 설정하기 순서로 사용한다.
- OpenStreetMap 타일은 인터넷 연결만으로 개발용 지도 시연이 가능하다. 기본 서울 중심은 현재 GPS 위치가 아니다. `flutter_map` 8.3.2 및 `latlong2` 0.10.1을 추가했으므로 `flutter pub get`으로 잠금 파일을 갱신해야 한다. 키 없이 지도에서 핀을 찍고 직접 장소명을 입력할 수 있다. 지도 장애 시 기존 텍스트 입력을 사용한다.
- 검색은 Geoapify의 한국 주소/장소 지오코딩을 이용하며 OpenAI와 독립적이다. https://myprojects.geoapify.com/ 에서 키를 발급해 서버 `.env`에 `GEOAPIFY_API_KEY=...`를 설정한 뒤 `npm start`로 서버를 실행한다. 결과는 데이터 제공처의 한국 장소 데이터에 따라 달라진다. 지도 핀 직접 선택 시 자동 주소 변환은 하지 않는다. GPS 및 기존 지도 탭 변경은 범위 외이다.
- `RecruitmentInput.location`에 확인된 장소명, 주소(있을 경우), 위도/경도를 저장하며 기존 글과 텍스트 입력은 호환된다. 장소명을 수동 수정하면 이전 좌표를 지운다. 좌표를 LLM 요청에 전송하지 않는다. 검색어는 Geoapify에 전송되므로 개인정보 대신 공개 운동 장소만 검색한다.
- 공개 OSM 타일은 소규모 수업 시연용이며 사용 정책(https://operations.osmfoundation.org/policies/tiles/)과 저작자 표시(https://www.openstreetmap.org/copyright)를 준수해야 한다. 대규모 서비스에는 별도 타일 공급자를 사용하고 `--dart-define=RECRUITMENT_TILE_URL=...`와 저작자 표시를 적절히 변경한다. 검색 API 이용약관 및 데이터 저장 조건도 실제 배포 전 검토한다.
- 적용 후 `flutter pub get`, `flutter analyze`, `flutter test`, `flutter run -d edge` 실행. `pubspec.lock` 변경도 본인 브랜치에 포함한다.

## 검증

- 서버 JS 문법 검사 통과. Node 테스트 26개(기존 17개, 모집글 6개, 장소 검색 3개) 통과. 환경에서 npm 의존성 다운로드가 불가능하여 SMTP 호출 시 오류를 내는 임시 nodemailer 스텁으로 서버 테스트만 실행했다. 스텁은 배포 파일에 포함하지 않는다. 실제 SMTP와 OpenAI API 호출은 검증하지 않았다.
- Flutter/Dart SDK가 없어 Flutter 분석, 신규 Dart 테스트 5개, 실제 브라우저 빌드는 실행하지 않았다. 로컬에서 반드시 확인한다.

- Geoapify 실응답, OSM 실제 타일 및 지도 상호작용은 실행 검증하지 않았다. API 키 없이 직접 등록 및 지도 선택이 가능하도록 설계했다.
