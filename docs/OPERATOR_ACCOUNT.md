# 운영자 계정 · 로컬 프로토타입

DEMO와 별개인 운영자 계정 1개를 서버에 생성합니다. 고정 비밀번호를 앱 코드에 넣거나 일반 회원가입으로 권한을 올리지 않습니다.

## 로그인

1. 저장소 루트에서 최초 1회 `npm run create-operator --prefix server`를 실행합니다. 이미 생성되어 있으면 덮어쓰지 않습니다.
2. `server/.operator-login.txt`에서 이메일과 생성된 비밀번호를 확인합니다. 이 파일과 `server/.operator-account.json`은 Git에서 제외되며 파일 권한은 소유자 읽기/쓰기입니다. 내용을 노션·채팅·GitHub에 공유하지 마세요.
3. `cd server && npm start`로 서버를 실행/재시작합니다.
4. 앱에서 로그아웃 → **운영자 로그인** → 파일의 비밀번호 입력. 계정 이메일은 `operator@exercise-assist.local`입니다. 일반 이메일 로그인 입력란에서도 이 주소로 로그인할 수 있습니다.
5. 로그인 후 운영 관리로 진입합니다. 일반 화면으로 나간 뒤에는 **내정보 → 운영 관리**에서 다시 열 수 있습니다.

계정은 현재 개발 환경에 생성해 두었습니다. SMTP/OpenAI 설정과 독립적으로 작동합니다. 이메일 수신용 계정이 아니므로 운영자 비밀번호를 이메일로 재설정하지 않습니다.

## 관리 범위

- **회원정보**: 이 브라우저에 저장된 일반/DEMO/운영자 프로필 검색, 닉네임·공통 설문·종목 설문 수정. 이메일·비밀번호·운영자 권한을 회원 편집에서 바꾸지 않습니다.
- **일정**: 회원별 일정 추가·수정·삭제·완료 상태 변경, 겹침 경고. 대상 회원의 내정보 캘린더와 홈 일정에 반영됩니다.
- **랭킹**: 표시 이름·운동 횟수 등록/수정/삭제. 횟수 내림차순, 동률은 ID 순으로 정렬해 홈 TOP 3와 랭킹 목록에 반영합니다. 실제 경기 결과로 자동 계산하는 기능은 아닙니다.
- **모집글**: 종목·제목·시간·장소·모집 조건·인원·설명·준비물 등록/수정/삭제. 관심 종목 추천·커뮤니티·상세 화면에서 같은 데이터를 봅니다. 예시 글과 운영자 등록 글을 구분하며 실제 참가 신청·예약은 아직 지원하지 않습니다.
- **변경 이력**: 성공한 운영 작업 최근 100건을 저장합니다. 위변조 방지 서버 감사 로그가 아닌 로컬 작업 기록입니다.

## 권한과 저장의 한계

서버는 scrypt 비밀번호 검증 후 무작위 운영자 세션을 발급합니다. 모든 운영자 변경 메서드는 서버 세션 확인을 통과해야 저장할 수 있습니다. 일반/DEMO 계정은 관리 경로와 변경 메서드 모두 차단됩니다. 8시간 만료, 로그아웃, 서버 재시작 후에는 재로그인이 필요합니다. 운영자 토큰은 메모리에만 있고 로컬 저장소/로그에 남기지 않으며 앱 재시작 시 로그인 상태도 복원하지 않습니다.

회원·일정·랭킹·모집 데이터는 여전히 **같은 브라우저/기기의 저장소**에 있습니다. 다른 기기/브라우저/동시에 열어둔 다른 탭에 자동 동기화하지 않습니다. 운영자 로그인에 성공해도 현재 브라우저에 없는 회원 데이터를 읽어오지는 않습니다. 로컬 저장소를 직접 수정할 수 있는 사람까지 방어하는 운영용 권한 시스템은 아닙니다. 실제 배포에는 서버 DB, 서버에서 처리하는 모든 CRUD와 권한 검사, HTTPS가 필요합니다.

계정/설문/캘린더의 기존 저장 형식(version 1)을 유지하고 `operations` 항목만 추가했습니다. 기존 데이터에는 예시 랭킹/모집 기본값을 적용합니다. 저장 실패 시 메모리 데이터와 변경 이력도 반영하지 않습니다.

## 코드·검증

- `server/admin-auth.mjs`, `server/create-operator.mjs`: 계정 생성·세션 인증
- `lib/admin/`: 관리 화면·입력 폼·서버 클라이언트·운영 데이터 모델
- `MemberRepository`: 변경 시 권한 확인, 기존 데이터 보존 및 저장
- `test/admin_test.dart`, `server/admin-auth.test.mjs`: 권한 거부, 위조 로컬 세션, 만료, 저장 실패, 기존 데이터 마이그레이션, 랭킹 반영, 일정 관리, 작은 화면 테스트
