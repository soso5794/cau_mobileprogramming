# 운동 Assist · HTTP 통신 과제

이번 제출은 **HTTP 방식**으로 구현했습니다. 앱이 Open-Meteo에 HTTPS GET 요청을 보내 현재 날씨와 24시간 예보 JSON을 받아 화면과 종목별 운동 환경지수를 갱신합니다. **별도 API 키나 Node 서버 없이 날씨 기능을 시연할 수 있습니다.**

- 제출 기준: 기본 브랜치 `main`
- 작업 브랜치: `assignment/http-communication_sangmin` (이력 보관)
- [과제 요구사항·시연 순서·구현 설명](docs/HTTP_ASSIGNMENT.md)
- [검증 결과](docs/HTTP_VALIDATION.md)
- 필수 제출 파일: `lib/`, `pubspec.yaml`. 별도 Flutter 이미지/폰트 asset을 사용하지 않아 `assets/`는 필요하지 않습니다.
- 저장소는 **2026년 12월 25일까지 공개 상태로 유지**합니다.

## 가장 빠른 시연

로그인 화면 → **DEMO 계정으로 둘러보기** → 농구 계정 → 홈 상단 **구름 아이콘(실시간 운동 날씨)**. 내정보의 **실시간 운동 날씨** 메뉴에서도 열 수 있습니다.

1. 현재 날씨와 선택 시간의 예보·환경지수를 확인합니다.
2. 장소를 잠실 또는 부산으로 바꾸면 새 HTTP 요청을 보냅니다.
3. 농구/런닝/축구, 시간대를 바꾸어 지수와 산정 이유를 비교합니다.
4. 새로고침으로 다시 조회합니다. 인터넷 연결을 끊고 새로고침하면 오류와 재시도 버튼을 확인할 수 있습니다.

기존 주간 계획·운동 분석은 **DEMO**로 표시되며 새 실시간 날씨 화면과 구분됩니다. 기존 AI 채팅은 별도 OpenAI 키와 서버가 필요한 다른 기능입니다.

## 이전 제출과의 관계

2026-11-17 Notion 팀 데모 ZIP을 기준으로 로그인·회원가입·내정보를 구현한 Flutter 프로토타입입니다. 기존 OUTIME 프로젝트(`exerciseapp/`)와는 별도 앱입니다.

## 이번 추가 기능: 캘린더 + 실제 AI API 연결

- **마이페이지 캘린더**: 월 이동·오늘·날짜별 일정 표시, 일정 추가/수정/삭제, 운동 완료, 시간 겹침 확인. 제목/종목/날짜/시간/운동 시간/장소/메모를 계정별로 저장합니다. 기존 계정도 그대로 불러옵니다.
- **AI 운동 도우미**: 더미 응답을 제거하고 OpenAI Responses API를 호출하는 로컬 Node 서버와 연결했습니다. 대화 기록·로딩·재시도·새 대화를 지원합니다.
- 사용자가 API 키 입력을 나중에 하기로 했으므로 **실제 OpenAI 답변은 아직 미검증**입니다. 키가 없으면 설정 안내를 표시합니다.
- AI 실행에는 앱 외에 `server/`에서 `npm start`가 필요합니다. [서버 설정 방법](server/README.md)을 확인하세요.

## 실행

검증 환경: Flutter 3.47.4 / Dart 3.13.3. 최소 버전은 `pubspec.yaml`을 따릅니다.

```sh
git clone https://github.com/soso5794/cau_mobileprogramming.git
cd cau_mobileprogramming
flutter pub get
flutter run -d chrome --web-port 7363
# 또는 Android 에뮬레이터/기기를 연결한 뒤
flutter run -d emulator-5554
```

Android Studio/VS Code에서는 **이 폴더를 프로젝트 루트로 열고 `lib/main.dart`를 실행**하세요. Android SDK 경로는 개발 환경에 맞게 설정됩니다. ZIP에 개인 PC의 `android/local.properties`는 포함하지 않습니다.

빠른 시연: 로그인 → **DEMO 계정으로 둘러보기** → 농구 / 러닝 / 축구 계정 → 하단 **내정보**.
새 계정 시연: 회원가입 → 공통 질문 → 선택한 종목 질문 → 자기소개 → 완료. **나중에**를 선택하면 내정보에서 다시 설정할 수 있습니다.

## 구현한 기능

- 이메일·비밀번호 로그인, 비밀번호 표시 전환, 로그인 유지, 재실행 시 세션 복원, 로그아웃.
- 회원가입 입력 검증, 중복 이메일·닉네임 검사, 비밀번호 확인, 로컬 프로토타입 안내 확인.
- 가입과 분리된 단계별 운동 프로필. 성별·나이·키는 선택 사항. 활동 지역·장소·시간대·목적과 마지막 자기소개.
- 농구: 빈도·시간, 실력, 선수 경험/경력, 포지션, 국적, 경기 형태.
- 러닝: 빈도·시간, 페이스, 거리, 워치 종류.
- 축구: 빈도·시간, 실력, 선수 경험/경력, 주발, 축구/풋살, 주·부포지션.
- 내정보: 프로필 수정, 종목별 정보/티어 상태, 즐겨찾기, 내 팀, 팀 신청 상태. 새 계정에는 가짜 팀·티어를 부여하지 않습니다.
- 설정: 알림 종류별 선호, 일정 알림 시점, 방해금지 시간, 다크 모드, 로그아웃.
- 수정 초안과 저장 값 분리, 취소 확인, 저장 실패 표시, 보호된 경로의 로그인 복귀.
- 홈·커뮤니티·지도·랭킹·내정보의 5개 탭. 홈에 TOP 3 자동 전환·개인 캘린더의 다가오는 일정·관심 종목 추천 모집을 표시합니다. 커뮤니티에서 설문에 저장한 종목 → 종목별 모집 → 상세 화면으로 이동합니다.

## 프로토타입 범위

계정·프로필·즐겨찾기·알림 선호는 **현재 기기의 앱 저장소**에 저장됩니다. 웹에서는 같은 브라우저·주소에서만 복원됩니다. 비밀번호는 임의 salt와 PBKDF2-HMAC-SHA256(600,000회) 검증값으로 보관하지만, 로컬 저장소는 운영용 인증이나 암호화된 개인정보 저장소가 아닙니다. 시연용 이메일/비밀번호를 사용하세요.

- **비밀번호 재설정**: SMTP 인증메일의 6자리 번호를 확인한 뒤 현재 기기의 비밀번호를 변경합니다. 서버 실행과 발신 SMTP 설정이 필요합니다. [설정·이용 안내](docs/PASSWORD_RESET.md). 서버 인증·가입 시 이메일 인증·실제 푸시 발송은 미연동입니다.
- DEMO 계정의 팀·티어·신청 내역은 시연 데이터입니다. 신청 취소도 기기 안에서만 반영됩니다. 선수 경험은 자기 신고이며 인증된 실력이 아닙니다.
- 알림 설정은 저장되지만 OS 알림 권한이나 예약 발송은 수행하지 않습니다.
- 테마와 기존 운동 장소 목록은 기존 메모리 상태를 유지합니다. 장소 목록은 계정 전환 시 초기화되며, 가입 설문에 입력한 주 활동 지역·장소는 계정에 저장됩니다.
- 실시간 운동 날씨는 실제 HTTP 응답을 사용합니다. 기존 주간 계획·운동 분석, 지도는 데모이며 모집·랭킹은 예시 또는 운영자 수동 관리 데이터입니다. 운영자는 모집글을 관리할 수 있지만 일반 회원의 작성·참가 신청과 자동 랭킹 산정은 미구현입니다. AI 도우미는 별도 로컬 서버를 사용하며 날씨 데이터를 자동 전달하지 않습니다. 코트 점유·예약 상태는 조회하지 않습니다.
- 모바일 플랫폼은 원본에 포함된 Android 기준이며 iOS 프로젝트는 추가하지 않았습니다.

```sh
flutter analyze
flutter test
flutter build web --release
flutter build apk --debug
```

제출본은 기본 브랜치 `main`에서 확인할 수 있습니다. 그룹 저장소 주소 https://github.com/soso5794/cau_mobileprogramming 를 제출하세요. 작업 브랜치 `assignment/http-communication_sangmin`은 이력 확인용으로 보관합니다.

추가 검증: `dart run tool/check_weather_api.dart`는 실제 앱과 같은 클라이언트/파서로 Open-Meteo를 조회합니다. [Open-Meteo API 문서](https://open-meteo.com/en/docs), [Flutter HTTP 가이드](https://docs.flutter.dev/cookbook/networking/fetch-data)를 참고했습니다. 날씨 데이터 출처: Open-Meteo, CC BY 4.0.

## 홈·커뮤니티 화면 확인

- **홈**: TOP 3가 5초마다 전환됩니다(일시정지/수동 선택 가능). 랭킹 탭과 같은 데이터를 사용하며, 초기 예시 항목과 운영자 수동 입력 항목을 구분합니다.
- **다가오는 일정**: 내정보 캘린더의 미완료·종료 전 일정을 시간순으로 최대 2개 표시합니다. 빈 상태에서는 일정 추가를 안내합니다. 카드에서 일정 내용과 메모를 확인할 수 있습니다.
- **추천 모집**: 저장된 관심 종목에 해당하는 예시/운영자 등록 모집을 즐겨찾는 종목 우선으로 최대 3개 표시합니다. AI/거리/실력 기반 추천은 아닙니다. 카드 선택 시 상세로 이동합니다.
- **커뮤니티**: 하단 커뮤니티 또는 홈의 커뮤니티 배너 → 설문에서 고른 종목만 표시 → 종목별 모집글. 관심 종목은 프로필 편집에서 변경합니다. 미선택/모집 없음도 빈 화면으로 안내합니다.
- 이전 `/match` 링크는 `/community`로 연결됩니다. 기존 `/sports` 주소는 홈 대시보드이며 종목별 프로필 편집 주소는 유지합니다.
- 검증: `test/home_community_test.dart`에서 관심 종목/계정 변경, 일정·추천, 상세 이동/뒤로, 랭킹 전환, 320px/1100px·200% 글자·다크 모드 레이아웃을 확인합니다.

## 운영자 계정

DEMO와 분리된 운영자 계정은 **로그인 → 운영자 로그인**에서 사용합니다. 이 브라우저의 회원 프로필·설문, 회원별 일정, 수동 랭킹, 모집글을 관리하고 변경 이력을 확인할 수 있습니다. 운영자 비밀번호와 설정법은 [운영자 계정 안내](docs/OPERATOR_ACCOUNT.md)를 참고하세요. 일반 계정에는 관리 메뉴가 표시되지 않으며 저장 요청도 거부합니다. 운영 데이터는 같은 기기의 로컬 저장이며 공용 DB 관리 기능은 아닙니다.
